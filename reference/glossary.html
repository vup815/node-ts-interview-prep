詞彙表

本課程使用的標準詞彙。所有課程都遵守這些定義。

Node.js Runtime

Event loop： Node.js 在單執行緒上處理非同步 callback 的機制。它循環經過多個 phase（timers → pending → poll → check → close），每個 phase 之間清空 microtask 佇列。

Phase： Event loop 的一個階段，處理特定類別的 callback。六個 phase 分別是 timers、pending callbacks、idle/prepare（內部）、poll、check、close callbacks。

libuv： 實作 event loop 和執行緒池的 C 函式庫。Node 把 I/O、計時器、部分系統呼叫委派給 libuv。

Microtask： 高優先級的 callback，在 event loop phase 之間執行，下一個 macrotask 之前。包含 process.nextTick（最高優先級）和 Promise.then/queueMicrotask。

Macrotask： 由 setTimeout、setInterval、setImmediate 或 I/O 排入佇列的 callback。每個 phase 一次處理一個 macrotask。

process.nextTick： 在下一個 event loop phase 之前執行的 microtask — 甚至比 Promise microtask 還早。過度使用會餓死 I/O。

setImmediate： 在 check phase（poll 之後）執行的 macrotask。用來把工作延後到 I/O callbacks 之後。

執行緒池（Thread pool）： libuv 管理的執行緒（預設 4 個），用來處理 CPU 密集或 blocking 的操作（fs、crypto、DNS）。不要和 JS 主執行緒搞混。

Stream： 以 chunk 為單位讀寫資料的抽象介面。四種型別：Readable、Writable、Duplex、Transform。

Backpressure： 當 Writable stream 跟不上 Readable stream 時發生的狀況。Node 透過 highWaterMark 和 drain 事件處理。

Buffer： 配置在 V8 heap 之外的一塊固定大小原始二進位資料。用於 streams、檔案 I/O、網路資料。

EventEmitter： Node 用來實作 pub/sub 的模式。許多核心模組（stream、http、fs）都繼承它。

CommonJS (CJS)： Node.js 原始的模組系統。使用 require() 和 module.exports，同步載入。

ES Module (ESM)： JavaScript 標準的模組系統。使用 import 和 export，非同步載入，可靜態分析。

TypeScript

泛型（Generic）： 型別參數，讓函式、class、型別能在保留型別安全的前提下適用於多種型別。寫為 <T>。

約束（Constraint）： 透過 extends 對泛型參數的限制。範例：<T extends { length: number }>。

Utility type： 內建的泛型型別，用來變換另一個型別。常見的：Partial<T>、Required<T>、Pick<T, K>、Omit<T, K>、Record<K, V>、ReturnType<T>、Parameters<T>、Awaited<T>。

收窄（Narrowing）： 使用 type guard（typeof、instanceof、in、discriminated unions）把 union type 收窄到更具體型別的過程。

Discriminated union： 一組物件型別的 union，每個成員有一個 literal 屬性（discriminant）。TypeScript 用這個屬性來收窄。範例：{ kind: 'success'; data: T } | { kind: 'error'; message: string }。

Type guard： 執行時期檢查的運算式，用來保證某個 scope 裡的型別。包含使用者自訂的型別謂詞（is T）。

Mapped type： 迭代另一個型別的 key 來變換其屬性的型別。範例：{ [K in keyof T]: T[K] | null }。

Conditional type： 根據條件選擇兩個分支之一的型別。範例：T extends string ? 'yes' : 'no'。

結構型別（Structural typing）： TypeScript 的型別相容性系統：兩個型別如果形狀相符就是相容的，不管名稱。也稱為 duck typing。

satisfies： TS 4.9+ 的運算子，檢查值的型別是否符合約束，但不拓寬型別。範例：const config = { port: 3000 } satisfies Record<string, unknown> — port 的型別保持 number，不會變成 unknown。

as const： 把值變成深度 readonly，並把所有型別收窄到 literal（而不是被拓寬）。範例：const roles = ['admin', 'user'] as const — 型別是 readonly ['admin', 'user']，不是 string[]。
