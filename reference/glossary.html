Glossary

Canonical terms for this workspace. All lessons adhere to these definitions.

Node.js Runtime

Event loop: The mechanism by which Node.js processes asynchronous callbacks on a single thread. It cycles through phases (timers → pending → poll → check → close), draining microtask queues between each phase.

Phase: A stage of the event loop that processes a specific category of callbacks. The six phases are timers, pending callbacks, idle/prepare (internal), poll, check, and close callbacks.

libuv: The C library that implements the event loop and the thread pool. Node delegates I/O, timers, and some system calls to libuv.

Microtask: A high-priority callback that runs between event-loop phases, before the next macrotask. Includes process.nextTick (highest priority) and Promise.then/queueMicrotask.

Macrotask: A callback queued by setTimeout, setInterval, setImmediate, or I/O. Macrotasks run during their respective event-loop phase, one per iteration.

process.nextTick: A microtask that runs before the next event-loop phase — even before promise microtasks. Overuse can starve I/O.

setImmediate: A macrotask that fires during the check phase (after poll). Use it to defer work until after I/O callbacks have run.

Thread pool: Four (by default) worker threads managed by libuv, used for CPU-heavy or blocking operations (fs, crypto, DNS). Not to be confused with the single JS thread.

Stream: An abstract interface for reading/writing data piece-by-piece. Four types: Readable, Writable, Duplex, Transform.

Backpressure: When a Writable stream cannot keep up with a Readable stream. Node handles it via highWaterMark and drain events.

Buffer: A fixed-size chunk of raw binary data allocated outside the V8 heap. Used for streams, file I/O, and network data.

EventEmitter: The pattern Node uses for pub/sub. Many core modules (stream, http, fs) extend it.

TypeScript

Generic: A type parameter that makes a function, class, or type work with any type while preserving type safety. Written as <T>.

Constraint: A restriction on a generic type parameter via extends. Example: <T extends { length: number }>.

Utility type: A built-in generic type that transforms another type. Common ones: Partial<T>, Required<T>, Pick<T, K>, Omit<T, K>, Record<K, V>, ReturnType<T>, Parameters<T>, Awaited<T>.

Narrowing: The process of refining a union type to a more specific type using type guards (typeof, instanceof, in, discriminated unions).

Discriminated union: A union of object types where each member has a literal property (the "discriminant") that TypeScript can use to narrow. Example: { kind: 'success'; data: T } | { kind: 'error'; message: string }.

Type guard: An expression that performs runtime checks to guarantee the type in a scope. Includes user-defined type predicates (is T).

Mapped type: A type that iterates over keys of another type, transforming its properties. Example: { [K in keyof T]: T[K] | null }.

Conditional type: A type that selects between two branches based on a condition. Example: T extends string ? 'yes' : 'no'.

structural typing: TypeScript's type-compatibility system: two types are compatible if their shapes match, not their names. Also called "duck typing."

satisfies: A TS 4.9+ operator that checks a value's type against a constraint without widening. Example: const config = { port: 3000 } satisfies Record<string, unknown> preserves the literal type of port.
