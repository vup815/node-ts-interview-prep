Lesson 9: 模擬面試題庫

實際面試中可能被問到的題目。每題都有解答範本。

參考：模擬面試複習

Event Loop

Q1: 解釋 Node.js 的 event loop。有哪些 phases？microtask 和 macrotask 的執行順序？

Event loop 由 libuv 實作，循環六個 phases：timers、pending callbacks、idle/prepare、poll、check、close callbacks。每個 phase 之間清空 microtask 佇列（nextTick 優先、Promise 次之）。所以 Promise.then 比 setTimeout(0) 先跑。

Q2: setTimeout(cb, 0) 和 process.nextTick 差在哪？

setTimeout 是 macrotask（timers phase），nextTick 是 microtask（phase 之間執行）。nextTick 一定先跑。但遞迴 nextTick 會餓死 event loop。現代寫法用 queueMicrotask 或 setImmediate。

Q3: 在 I/O callback 裡面，setImmediate 和 setTimeout(0) 哪個先跑？

setImmediate。因為在 I/O callback 裡時 event loop 在 poll phase，之後走到 check（setImmediate），再經過 timers phase 才到 setTimeout。外部不確定，內部 always setImmediate。

Utility Types

Q4: Partial、Pick、Omit 分別做什麼？舉使用情境。

Partial 讓全部欄位 optional（PATCH body）。Pick 選取子集（API 投影）。Omit 移除欄位（隱藏機密）。組合：Partial<Omit<User, 'id'>> = id 不能改，其他可選。

Q5: Record、ReturnType、Awaited 的用途？

Record 建立有固定 key 的字典（設定、權限）。ReturnType 取出函式回傳型別（不要重複定義）。Awaited 解開 Promise。組合：Awaited<ReturnType<typeof fn>> 從 async 函式推導真實型別。

Interface / Type / Class

Q6: Interface 和 type 的差別？什麼時候用哪個？

Interface 可以 declaration merging（擴充第三方型別時用）。Type 支援 union、tuple、mapped types（預設用 type）。資料形狀用 type，擴充用 interface，行為用 class。

Streams & Error Handling

Q7: 為什麼用 streams 比 readFile 好？解釋 backpressure。

記憶體效率：2GB 檔案用 readFile 佔 2GB RAM，stream 佔 ~64KB pipe 自動處理 backpressure — 寫入端跟不上時暫停讀取，等 drain 事件恢復。

Q8: Express 4 的 async route handler 拋錯會怎樣？怎麼修正？

Express 4 不會接 async 錯誤 — 變成 unhandled rejection，可能 crash process。修正：包 try/catch 並呼叫 next(err)。Express 5 原生支援。

Thread Pool

Q9: Node 是單執行緒嗎？怎麼處理並行？CPU 密集工作會發生什麼？

JS 跑在主執行緒，但 libuv 提供 4 個 thread pool 處理 fs/crypto/DNS。網路 I/O（HTTP/TCP）不走 thread pool，是 OS 層非同步。CPU 密集工作會佔住主執行緒、凍結 event loop。解法：worker_threads、cluster。
