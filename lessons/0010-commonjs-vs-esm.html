Node.js Interview

Lesson 10: CommonJS vs ESM

Node.js 的兩個 module system — 面試必考。

Why This Matters

Interviewers love "What's the difference between require and import?" It tests whether you understand synchronous vs asynchronous loading and the ongoing ecosystem migration.

1. The Two Systems

CommonJSES Modules
Syntaxrequire / module.exportsimport / export
LoadingSynchronousAsynchronous
Default.js (no type:module).mjs or type:module
Tree-shakingNot possibleSupported
Top-level awaitNot supportedSupported

2. Syntax

// CJS
const fs = require('fs');
module.exports = { myFunc };

// ESM
import fs from 'fs';
export const myFunc = () => {};

3. Sync vs Async

// CJS: blocks until loaded
const lodash = require('lodash');
console.log('ready');  // after lodash loaded

// ESM: hoisted
import lodash from 'lodash';
console.log('ready');  // after all modules parsed

4. Interview Script

"New projects should use ESM — it's the standard, supports tree-shaking, and top-level await. CommonJS is still widespread in existing codebases. The fundamental difference: require is synchronous and can be conditional; import is static and hoisted."
