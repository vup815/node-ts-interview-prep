## How Lessons Work

Each lesson is a self-contained HTML file (links a shared [stylesheet](assets/style.css)):

- **Knowledge first** — the minimum required to acquire the skill
- **Interactive puzzles** — click-to-reveal answers with explanations
- **Interview answer scripts** — what to say aloud when asked
- **Primary sources** — links to the authoritative docs
